Thailand Post Integration Setup

ใช้ไฟล์นี้เป็น checklist สำหรับติดตั้งระบบซิงก์สถานะพัสดุ Thailand Post ใน PDH Telemed

1. รันฐานข้อมูล

source database_setup_thailand_post.sql;

ไฟล์ SQL จะเพิ่ม column ใน telemed_tracking, สร้าง log table และ view สำหรับรายงาน โดยไม่ลบข้อมูลเดิม

ถ้าต้องการสร้างฐานใหม่ทั้งก้อน ให้ใช้ไฟล์นี้แทน:

source pdhtawan_schema_full.sql;
ไฟล์ pdhtawan_schema_full.sql มีคำสั่ง DROP TABLE เหมาะกับฐานใหม่หรือเครื่องทดสอบเท่านั้น

2. ตรวจสอบ API key

ตั้งค่าใน thailand_post_config.php หรือกำหนด environment variable:

THAILAND_POST_API_KEY=your_api_key
ไม่ควรเผยแพร่ API key ใน repository สาธารณะ

3. ตรวจสอบไฟล์ที่ต้องมี

  • thailand_post_config.php
  • api_thailand_post.php
  • thailand_post_modal.php
  • logs/

4. ตรวจ syntax PHP

php -l thailand_post_config.php
php -l api_thailand_post.php
php -l thailand_post_modal.php
php -l tracking.php

5. ทดสอบการใช้งาน

  1. เปิดหน้า tracking.php
  2. กดปุ่ม Thailand Post ในแถวผู้ป่วย
  3. กรอกเลขพัสดุ เช่น EV123456789TH
  4. กด ตรวจสอบ
  5. กด บันทึกและซิงก์
เมื่อติดตั้งสำเร็จ ระบบจะแสดงเวลา TP sync ในคอลัมน์เลขพัสดุ และบันทึกผลลงฐานข้อมูล
